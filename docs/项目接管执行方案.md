### 0.1 关于插件名的技术约束（需知悉）

npm 硬性禁止大写包名（`npm publish` 会直接报 `Invalid name`）。因此拆成两层：

| 层 | 取值 | 说明 |
|---|---|---|
| **显示名** | `Mao-pet` | README 标题、图标名、UI 展示 |
| **npm 包名** | `mao-pet`（或 `@<scope>/mao-pet`） | 发布前需查名可用性；若重名则加 scope |
| **cordis id** | `mao-pet` | 与 whale-widget 的 `dsh-whale-widget` 同为全小写惯例 |

> 顺带：这个名字天然避开了 §7.3 说的 `pet` 撞车问题，无需额外处理。

### 13.1 ★★ 重大发现：block-tree 问题**只存在于手工改压缩产物**，回仓后自然消失

M0 定位的根因是「手改节点落在 `(openBlock(), createBlock(...))` 区块内 → 被 `patchBlockChildren` 跳过」。
本轮**实测验证了它的边界**：

1. 用 `.vue` 模板重写 `PetAppearancePanel`（含反馈 div），`vite build` 后检查产物——

2. 把这份新产物 **实际组装进 dist**（compose-dist + trim-pages），无头浏览器实测点击「保存」：

   ```

   t2600:   display:none, ""            ← 随 busy 结束自动隐藏
   ```
