## 3. 逐项行为规范

### 3.1 历史加载 `_load(full)`

```js
function _load(full) {
  fetch(`/api/xiaozhi/chat-history?limit=${full ? 1000 : 100}`)
    .then(r => r.json())
    .then(j => {
      if (!j.ok || !j.history) return
      let added = 0
      for (const it of j.history) {
        const id = it.id || 0
        const role = it.role === 'user' ? 'user' : it.role === 'system' ? 'system' : 'assistant'
        let text = it.type === 'image'
          ? (it.text && it.text !== ' ' ? `[图片] ${it.text}` : '[图片]')
          : it.text
        const image = it.type === 'image' && it.image_base64
          ? `data:image/jpeg;base64,${it.image_base64}` : null
        // 双去重 + 三条过滤
        if (role === 'system' && (text.includes('重连') || text.includes('连接中断'))) continue
        if (id && seenIds.has(id)) continue
        if (role === 'assistant' && z.value.some(m => m.role === 'assistant' && !m.id &&
            (text.startsWith(m.text) || m.text.startsWith(text)))) continue
        if (role === 'user' && it.type !== 'image' && seenFp.has(`u|${text.slice(0, 80)}`)) continue
        z.value.push({ role, text, image, id })
        if (id) seenIds.add(id)
        if (role === 'user' && it.type !== 'image') seenFp.add(`u|${text.slice(0, 80)}`)
        added++
      }
      if (added && N.value) nextTick(scrollToBottom)
    })
    .catch(() => {})
}
_load(true)                                  // 首载全量 1000
setInterval(() => _load(false), 3000)        // 每 3s 增量 100
```

**四条去重/过滤规则（必须逐条保留）**：
| 规则 | 目的 |
|---|---|
| `system` 含「重连 / 连接中断」跳过 | 避免频繁刷屏（配合后端 `_syslog(quiet=True)`） |
| `id && seenIds.has(id)` 跳过 | 按 id 主去重 |
| `assistant` 且与某条 `id=null` 的临时分句互为前缀 → 跳过 | **逐句气泡 vs 完整历史** 不重复（`3a26ab01` 核心） |
| `user` 且非图片 且 `seenFp` 命中 → 跳过 | 本地回显去重；**图片消息跳过**（`02d97ba7` 修复同文本图片被吞） |

### 3.2 重建 seen 集合 `qe()`

```js
  }
  // ...重连
}
```
⚠ `qe()` 里 seenFp 是**无条件**添加（与 `_load` 里的条件不同），这是原样行为，需保留。

### 3.3 WS 字符串消息 `Ke(data)`

| type | 行为 |
|---|---|
| `sysmsg` | **忽略**（不 push 文本；由历史轮询渲染） |
| `hello` | `R=true`；`H=session_id`；**`G` 重置为 3000**；发 `{type:'stop'}` 给桌宠 |
| `llm` | `V=true`；有 `emotion` 则发桌宠 emotion |
| `tts` start | 停音频、发桌宠 `speaking:true` |
| `tts` sentence_start | **`V=false`**；发桌宠 `{type:'text'}`；发桌宠 speaking |
| `tts` stop | 发桌宠 `stop`/`speak_stop`/`speaking:false`；`V=false` |
| `pet_text` | **`V=false`**；`z.push({role:'assistant', text, id:null})`；跟随则滚动 |
| `error` | `R=false`；`V=false` |

> **与 `0b8731f3` 描述一致**：WS **不 push 文本到消息列表**（除 `pet_text` 逐句）。
> `sysmsg` 与 `tts sentence_start` 的文本由历史轮询渲染，消除"回复两遍"。

### 3.4 二进制音频 `Ge(data)`

```
帧格式：uint32 LE = 采样率 | uint32 LE = 声道数(1..8) | float32 LE PCM 交错
校验：byteLength >= 8；rate>=1；channels 1..8；8 + rate*4*channels <= byteLength
播放：createBuffer(channels, rate, 48000) → copyToChannel → 队列 → 顺序 AudioContext 播放
```
- `Y` = 下一个可播放时间点，`Math.max(currentTime + 0.03, Y)`
- `Z()` = 停止：清 `onended`、`stop()`、清空 `X`/`q`、`J=false`、`Y=0`

### 3.5 重连 `Je()`

```js
function Je() {
  clearTimeout(W)
  W = setTimeout(qe, G)              // G 起始 3000
  G = Math.min(15000, Math.round(G * 1.6))   // 指数退避，上限 15s
}
```
`hello` 收到时把 `G` 重置回 3000。
